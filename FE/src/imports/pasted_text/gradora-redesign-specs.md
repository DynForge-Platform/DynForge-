Redesign the entire Gradora web platform into a premium, trustworthy, modern academic tutoring and mentorship marketplace.

PROJECT CONTEXT
Gradora is a web platform where university students can find verified senior students, alumni, lecturers, or academic mentors to help them with courses, assignments, research, thesis, career advice, and academic planning. The platform includes safe booking, escrow payment protection, mentor verification, course-based search, session scheduling, student dashboard, mentor onboarding, resources, and admin revenue management.

The current visual direction should be improved, not completely changed. Keep the identity: clean academic platform, blue as the primary brand color, white/light background, cards, rounded corners, trustworthy escrow system, university-focused mentoring.

OVERALL DESIGN STYLE
Create a polished SaaS + education marketplace interface.
Style keywords:
- Premium academic
- Trust-first
- Clean university mentoring platform
- Modern SaaS dashboard
- Friendly but professional
- Calm, spacious, well-aligned
- High readability
- Strong hierarchy
- Consistent components across all pages

VISUAL LANGUAGE
Use a light background with soft blue-tinted surfaces.
Primary color: deep royal blue / electric blue.
Secondary colors: navy, soft lavender, pale blue, mint green for success, amber for rating, red for warning.
Avoid overusing saturated blue. Use it only for main CTAs, selected states, and key highlights.
Use plenty of white space.
Use soft cards with subtle shadows and thin borders.
Rounded corners should be consistent, around 12–20px depending on component size.
Use clean icons with consistent stroke style.
Use high-quality mentor avatars, academic images, and subtle illustration accents.
Do not make the design childish. It should feel like a serious but friendly university product.

TYPOGRAPHY
Use one consistent modern typeface system.
Recommended:
- Headings: Sora, Plus Jakarta Sans, or Inter Display
- Body: Inter
Do not mix too many fonts.
Headings should be bold, clear, and modern.
Body text must be readable and not too small.
Use consistent font scale:
- Hero title: 56–72px desktop
- Page title: 36–44px
- Section title: 24–32px
- Card title: 16–20px
- Body: 14–16px
- Caption: 12–13px

BRAND FEEL
Gradora should feel like:
“Airbnb for verified academic mentors, with Stripe-like trust and Notion-like clarity.”
It should look better than a normal university project.
It should feel investable, credible, and ready for real users.

GLOBAL LAYOUT
Create a consistent layout system:
- Desktop width: 1440px
- Main content max width: 1180–1240px
- 12-column grid
- Header height: around 72px
- Footer consistent across public pages
- Dashboard uses sidebar + main content layout
- Consistent spacing: 8px system, section padding 80–120px

NAVIGATION
Create a unified top navigation:
Left: Gradora logo
Center: Find Mentors, Become a Mentor, Resources, About
Right when logged out: Log In, Join Now
Right when logged in: user name, avatar, dropdown
Use clear active navigation state.
Make the logo clean and professional.

IMPORTANT UX IMPROVEMENTS
Fix all inconsistencies from the current design:
- Do not repeat the same mentor profile accidentally.
- Keep dates consistent.
- Make durations mathematically correct.
- If a session is 90 minutes, show 90 minutes, not 180 minutes.
- Use one currency format consistently.
- If using Vietnamese dong, show “₫” or “VND”.
- If using USD, show “$”.
- Do not mix both randomly.
- Make all buttons consistent.
- Make card sizes consistent.
- Make footer consistent.
- Make payment and escrow flow feel more trustworthy and legally clear.
- Do not make admin panel look disconnected from the public website.
